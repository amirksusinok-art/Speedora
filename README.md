# Speedora

Сайт для проверки скорости и качества интернет-соединения. Интерфейс на React; небольшой сервер отдаёт IP-данные и DNS-записи.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Для проверки готовой сборки: `npm run build`, затем `npm start` и `http://localhost:3001`.

## Источники и ограничения

- Speed Test использует официальный модуль `@cloudflare/speedtest` и сеть Cloudflare. Каждый запуск передаёт до ~12,2 МБ скачивания и ~12,2 МБ отправки плюс небольшие служебные запросы. Cloudflare собирает обезличенные результаты измерений согласно документации модуля.
- ISP и приблизительное местоположение: ipapi.is. VPN/прокси: proxycheck.io (без ключа — до 100 запросов в день с IP сервера). Для увеличения лимита можно задать `PROXYCHECK_API_KEY` в окружении сервера.
- DNS Lookup: DNS-резолвер сервера. DNS Speed Test выполняет браузерные HTTPS-запросы к Cloudflare и Google; это время ответа всего запроса, включая сетевой путь, и оно не отражает настройку системного DNS.
- Streaming и Wi-Fi оценки вычисляются из последнего Speed Test. Доступность конкретных видеосервисов и уровень радиосигнала Wi-Fi браузером не проверяются.
- Результаты не сохраняются между посещениями.
